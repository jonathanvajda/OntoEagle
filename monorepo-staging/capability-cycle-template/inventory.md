# Function Inventory

## How to Fill This Out

Create one copy of this file for each capability family, such as `rdf-parsing/inventory.md` or `browser-file-io/inventory.md`.

Use this file during the survey pass. Do not refactor while filling it out. The purpose is to capture what exists, where it lives, how it behaves, and which functions may overlap.

Every candidate function should receive one row. If a function is nested inside another function, record it anyway and note the parent function in `Location notes`.
