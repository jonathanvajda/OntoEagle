# Overview

## Primary Deployment (Required)
Basic web service at localhost. A user's own local environment at localhost at some arbitrary port.

This deployment involves HTML, CSS, and JS ready, out-of-the-box.
This deployment does not require a back-end server for any of the app's functions.
This deployment does not require any command line builds (or CI jobs) to produce the final product. E.g., React requires TypeScript to be converted into the respective files.
