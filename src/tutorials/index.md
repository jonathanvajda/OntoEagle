# OntoEagle Tutorials

Tutorials and sample artifacts for browser-based ontology-development workflows in OntoEagle.

## CQ Ferret Tutorial

A hands-on tutorial for using CQ Ferret and the extracted vocabulary page to collect competency questions, contributors, data sources, diagrams, query notes, and vocabulary candidates.

- [Read the CQ Ferret tutorial](cq-ferret-tutorial.md)
- [Download sample CQ CSV](sample-cq-ferret-import.csv)
- [Download sample vocabulary CSV](sample-vocabulary-export.csv)

## Axiolotl Tutorial

A hands-on tutorial for using Axiolotl to load RDF into a browser-local active workspace, run SPARQL, save reusable queries, materialize inferred triples, and export review artifacts.

- [Read the Axiolotl tutorial](axiolotl-tutorial.md)
- [Download sample Axiolotl RDF graph](sample-axiolotl-graph.ttl)
- [Download sample saved-query CSV](sample-axiolotl-saved-queries-import.csv)
- [Download sample saved-query JSON-LD](sample-axiolotl-saved-queries.jsonld)

## Mermaid Project IDE Tutorial

A hands-on tutorial for using the deployed [Mermaid Project IDE](https://skreen5hot.github.io/mermaid/) to create browser-local diagram projects, preview Mermaid syntax in split view, manage `.mmd` files, export project bundles, and draft semantic design patterns for ontology work.

- [Read the Mermaid Project IDE tutorial](mermaid-project-ide-tutorial.md)

## Knowledge Graph Modeler Tutorial

A hands-on tutorial for using the deployed [RDF Knowledge Graph Modeler](https://skreen5hot.github.io/kgModeler/) to create ontology-backed instance diagrams, assign `rdf:type`, draw object-property assertions, and export Mermaid or Turtle artifacts.

- [Read the Knowledge Graph Modeler tutorial](kg-modeler-tutorial.md)
